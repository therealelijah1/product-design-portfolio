# UnifiedBeez: Founding Product Designer

## Role
Founding product designer: owned UX research, information architecture, UI and the design system from zero.

## Problem
Small businesses juggle customer conversations across WhatsApp, Instagram, email and web chat, and lose leads between apps.

## Approach
- Mapped the conversation journey across channels with early users
- Designed a unified inbox with channel-aware message threads
- Built a component library so new features shipped consistently

## Key screens
- Unified inbox
- Contact profile with cross-channel history
- Automation builder

## Learnings
Designing for speed of reply mattered more than feature depth.
