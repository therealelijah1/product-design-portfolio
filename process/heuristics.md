# UX review heuristics

Used for quick audits before a redesign.

1. **Visibility of status:** the user always knows what is happening.
2. **Match the real world:** labels use the customer's words, not internal ones.
3. **User control:** easy undo and clear exits.
4. **Consistency:** same action, same look, same place.
5. **Error prevention:** constraints and defaults stop mistakes before they happen.
6. **Recognition over recall:** options are visible, not memorized.
7. **Efficiency:** shortcuts for frequent tasks.
8. **Minimal design:** every element earns its place.
9. **Helpful errors:** plain language, cause, and a fix.
10. **Help when needed:** contextual, searchable, short.
